# Supplementary Material for the paper "Kinship networks, kinlessness and supportive friendship at different ages. Evidence from Italy in 1998 and 2016"

This repository contains the Supplementary Material associated with the article “Kinship networks, kinlessness and supportive friendship at different ages. Evidence from Italy in 1998 and 2016”.

It includes seven Excel workbooks, corresponding to Figures 2-8 and the related tables, with results organized by year (1998 and 2016), sex (males, females, and both sexes combined), age group, and kinship category, where applicable.

The files report the estimates presented in the Supplementary Material together with their 84% confidence intervals. This repository is intended to support the transparency, reproducibility, and verification of the reported results.

## Accessing the supplementary tables

The supplementary tables are provided as Excel workbooks. 
Anonymous GitHub does not support the direct preview of `.xlsx` files.

To download a workbook:

1. Open the desired table using one of the links below.
2. Select the **downward-arrow icon** displayed above the file.
3. Open the downloaded workbook in Microsoft Excel or another compatible spreadsheet application.

Please note that any unreadable characters displayed in the browser represent the binary content of the Excel workbook and do not indicate that the file is corrupted.
